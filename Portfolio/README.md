# Shourya Sinha — Portfolio

My personal portfolio website, built with plain HTML, CSS and JavaScript (no frameworks).

## Features

- Light / dark theme (remembers your choice)
- Typewriter intro and interactive code-runner section
- Skills, projects (with category filter) and education sections
- Contact form with validation
- Responsive on mobile and desktop

## Run it

Clone the repo and open `index.html` in your browser.

```bash
git clone https://github.com/ShouryaS-dev/<repo-name>.git
```

## Files

- `index.html` – page content
- `style.css` – styling
- `script.js` – interactivity
